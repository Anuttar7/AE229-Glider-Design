# AE229 Glider Design Project

> **AE229 — Glider Design, Testing & Performance Analysis | IIT Bombay**

## 📌 Overview

This repository contains the report and design work for the **AE229: Glider Design** project. The project focuses on designing, testing, and evaluating lightweight gliders, with particular attention to:

- 🛩️ Lift and drag performance
- 📈 Glide performance
- ⚖️ Stability
- ✈️ Practical flight behaviour

### Glider Designs

Two glider configurations were explored during the project:

| Design | Description |
|---|---|
| **Glider 1** | An airfoil-based wing design intended to improve lift and glide performance. |
| **Glider 2** | A simplified design developed after evaluating the sensitivity and practical limitations of Glider 1. |

The report covers **design considerations, flight testing, wind-tunnel measurements, lift-to-drag calculations, and drag-polar analysis**.  
*Report, pp. 1–10.*

---

## 📊 Key Results

The main experimental and design outcomes reported by the team are:

- **Glider 1:** Estimated \(C_L/C_D = 4.06\) from the flight-test calculation.
- **Wind-tunnel testing:** Lift increased from **15 gm at −5°** to **76 gm at 10°**, followed by a slight reduction to **74 gm at 15°**.
- **Glider 1 configuration:** The airfoil-based configuration produced higher lift but was found to be sensitive to small imbalances.
- **Glider 2:** Adopted a simpler **Depron construction** with adjustable elevator geometry.
- **Drag-polar analysis:** The reported data show a reduction in \(C_L/C_D\) from **5.12 to 3.08** across the measured lift-coefficient range.

## 🔬 Experimental Analysis

The project combines **design and fabrication** with experimental aerodynamic evaluation. The performance of the gliders was assessed using:

- Flight-test calculations
- Wind-tunnel measurements
- Lift-to-drag ratio calculations
- Drag-polar analysis
- Evaluation of stability and sensitivity

This allowed the team to compare the performance and practical limitations of the two designs.
